AI must not be used to read code from or generate code for this repository.

"AI" in this case means a Large Language Model ("LLM"), such as ChatGPT, Claude, Copilot, Grok, etc.

AI-generated code is based upon sources of unknown origins and may introduce conflicting license terms if it includes code from other projects.

SDL has found that AI will frequently hallucinate issues that are not actually problems in practice, report incorrect information, and describe problems that are actually not issues at all.
